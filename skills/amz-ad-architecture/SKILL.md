# 亚马逊中文广告架构

## 核心标准

按用户指定的广告活动数量、定向类型、总预算和站点设计架构。不得擅自增加活动、修改 Listing 或改变用户已确认的预算约束。

广告活动名称使用中文，推荐结构：`产品型号-活动职责-定向类型-阶段`，例如：

- `U08-精准核心-新品期`
- `U08-词组拓词-新品期`
- `U08-自动探索-新品期`

每个活动必须写清：活动职责、预算金额、预算占比、分配原因、竞价策略、广告位、CPC 依据、主要风险、调整触发条件。

创建成本、CPC 和名词解释工作表前，读取 [成本-CPC 公式与名词口径](references/cost-cpc-glossary.md)。

## 必须建立的工作表

每份广告架构 Excel 必须包含以下工作表；可以调整名称中的产品型号，但不得省略功能：

1. `广告架构总览`
2. `CPC参数模型`
3. `成本利润模型`
4. `指标名词解释`
5. `否词与流量隔离`
6. `7天优化规则`
7. `数据来源与公式`

按实际需要增加活动明细表，例如：精准广告、词组广告、自动广告、广泛广告、商品投放、竞品 ASIN、广告位策略、搜索词迁移。不要为了凑结构建立无用工作表。

## 广告架构总览

展示并校验：

- 总日预算、售价、阶段性目标 ACOS、数据日期和成本模型状态。
- 每个活动的中文名称、定向类型、日预算、预算占比、竞价策略和广告位溢价。
- 每个活动承担的任务及不承担的任务。
- 为什么这样分预算、为什么使用当前 CPC、可能出现的错流量和处理方式。
- 所有活动预算合计必须等于用户指定总预算。

## CPC 参数模型

设置明显的可编辑输入区，至少包含：售价、目标 ACOS、总日预算、各活动预期 CVR、预算占比、广告位加价和竞价安全系数。

使用可审计公式：

- `目标CPA = 售价 × 目标ACOS`
- 成本完整时：`理论最高CPC = MAX(0, MIN(目标CPA, 盈亏平衡CPA) × 预期CVR)`
- 成本缺失时：`理论最高CPC = 目标CPA × 预期CVR`，同时强制显示“成本待补全”，不得宣称利润安全。
- `CPC压力 = 平均起始竞价 ÷ 理论最高CPC`
- `预计SKU预算 = 活动预算 × SKU计划占比`
- `预计点击容量 = 预计SKU预算 ÷ 平均起始竞价`
- 仅采用“动态竞价－只降低”时：`位置后最高竞价 = 最高基础竞价 × (1 + 广告位加价)`

若采用“动态竞价－提高和降低”，必须增加可编辑的“动态上调上限”，使用 `位置/动态后最高竞价 = 最高基础竞价 × (1 + 广告位加价) × (1 + 动态上调上限)`，并据此反推基础竞价上限；不得继续套用“只降低”的位置后竞价公式。

从活动明细表用公式取得平均起始竞价和最高基础竞价。最终竞价同时接受市场数据折扣价、理论最高 CPC 和安全系数约束，原则上取较低值。

至少提供三层判断：

- CPC 压力：≤65%“有余量”；65%–85%“接近上限”；85%–100%“临界”；>100%“超过上限”。
- 位置后最高竞价是否超过理论最高 CPC。
- 目标 ACOS 和目标 CPA 是否同时低于对应盈亏平衡值。

“CPC 压力”是内部风险指标，不是 Amazon 官方字段，也不等于市场竞争激烈程度。

## 成本利润模型与联动

把售价和目标 ACOS 只保留为 CPC 参数模型中的唯一输入；成本表只读联动，避免循环引用。

每个 SKU 单独填写以下每单成本：

- 采购成本、人民币兑美元汇率、单件分摊头程、FBA 配送费。
- 佣金率、Coupon/促销成本、退货率、单次退货损失、其他变动成本。
- 两个装必须填写“一个售出双只装 SKU”的整套成本，不能只填单只成本。

采购、头程、FBA 和佣金率是最低必填项；使用人民币采购成本时汇率也必须填写。Coupon/促销、退货和其他变动成本必须显式填 0 或注明假设，不能把空白默认为 0。任一必填项缺失时，盈亏平衡 ACOS、盈亏平衡 CPA 和安全差额必须留空，状态显示“待补全”；不得把空白按 0 成本参与安全判断。

使用以下公式：

- `采购成本($) = 采购成本(¥) ÷ 汇率`
- `佣金 = 有效成交价 × 佣金率`
- `退货预估成本 = 退货率 × 单次退货损失`
- `广告前总成本 = 采购 + 头程 + FBA + 佣金 + Coupon/促销 + 退货预估 + 其他变动成本`
- `广告前贡献利润 = 售价 - 广告前总成本`
- `盈亏平衡CPA = 广告前贡献利润`
- `盈亏平衡ACOS = 盈亏平衡CPA ÷ 售价`
- `CPA安全差额 = 盈亏平衡CPA - 目标CPA`

把盈亏平衡 ACOS、盈亏平衡 CPA 和成本状态回传 CPC 参数模型，并用盈亏平衡 CPA 约束理论最高 CPC。

若盈亏平衡 CPA 小于等于 0，状态显示“广告前已无贡献利润”，理论最高 CPC 归零，不得标记为可安全投放。

若售价已填写 Coupon 后的有效成交价，Coupon 列只填写兑换费等额外费用，不得再次扣除优惠金额；若售价使用原价，才填写每单实际折扣与费用。

盈亏平衡只代表利润约为 0，不等于建议长期目标。若用户要求保留利润，目标 ACOS 必须低于盈亏平衡 ACOS。

## 指标名词解释

建立独立工作表，至少包含：类别、名词、英文/缩写、计算公式、通俗解释、判断标准、实际操作、常见误区、所在表。

至少解释：

- 目标 ACOS、盈亏平衡 ACOS、预期 CVR。
- 目标 CPA、盈亏平衡 CPA、CPA 安全差额。
- 理论最高 CPC、平均起始竞价、CPC 压力、竞价安全系数。
- 最高基础竞价、广告位加价、动态上调上限、位置后最高竞价、位置/动态后最高竞价。
- 预计 SKU 预算、预计点击容量、平均 CPC 判断、最高竞价判断。
- 动态竞价－只降低、否定精准、否定词组。

明确区分“竞价”与“实际 CPC”。广告位加价是百分比乘数，位置后最高竞价是计划竞拍上限，不等于实际扣费。

## 活动明细与 CPC 依据

关键词活动至少展示：关键词、匹配方式、搜索量、购买率或转化参考、市场 CPC、起始竞价、起始/市场比例、广告位后竞价、CPC 说明、调整触发。

自动活动拆分紧密匹配、宽泛匹配、同类商品、关联商品，分别设置开关、竞价、职责和停用条件。商品投放展示 ASIN 选择标准、竞价、价格/评分差异和排除规则。

不要统一使用一个 CPC，也不要直接照抄市场建议价。综合相关性、搜索意图、匹配宽度、市场 CPC、CVR 假设、预算点击容量、成本约束和产品阶段决定起始价。

## 否词与流量隔离

分别列出：

- 初始否定精准与否定词组。
- 明显不相关的功能、部位、品类、礼品或人群词。
- 竞品品牌词和不适合的 ASIN。
- 暂不否定但需要观察的真实购买意图词。
- 精准、词组、自动之间的流量路由规则。

出单搜索词迁入精准后，在来源活动添加否定精准，避免重复竞价；不要误用否定词组屏蔽仍需探索的长尾。

## 7 天优化规则

用表格按时间和触发条件写清动作：

- 第 1–3 天保持结构稳定，只处理明显错流量和异常消耗。
- 曝光不足时按小步幅加价，避免一次性追到市场 CPC。
- 相关词达到设定点击阈值无单时降价；继续无单再暂停或否定。
- 搜索词达到订单与 ACOS 标准时迁入精准，并在来源活动否定精准。
- 第 7 天用实际`订单÷点击`替换模型中的规划 CVR。
- 预算调整只能在活动间转移，调整后总预算保持不变。

点击阈值、订单门槛和 ACOS 标准应结合售价、转化率、利润和样本量设置，不机械套用固定数字。

## 数据来源与公式

记录每项数据的文件名或来源、数据日期、字段定义、计算公式、适用范围与限制。引用外部研究时写入可访问 URL。

至少说明：售价口径、成本输入、市场 CPC、购买率/CVR、目标与盈亏平衡 CPA/ACOS、预算占比、广告位后竞价、理论最高 CPC 和迁移规则。

## 表格交付要求

使用表格工具创建或修改 Excel，保留公式，不把计算结果全部硬编码。输入区、计算区、风险区采用清晰颜色区分。

交付前必须：

- 校验活动预算合计。
- 检查公式引用与公式错误。
- 检查每个活动是否有预算和 CPC 说明。
- 验证成本缺失时不会输出虚假的 0 成本或“安全”状态。
- 验证盈亏平衡 CPA 小于等于 0 时理论最高 CPC 为 0，且状态不是“安全”。
- 在不写入交付文件的测试副本中填入临时成本，确认成本 → 盈亏平衡 ACOS/CPA → 理论最高 CPC → 活动竞价与风险状态能够连续重算。
- 渲染并复核全部工作表的可读性。
- 只在用户要求时修改 Listing。
