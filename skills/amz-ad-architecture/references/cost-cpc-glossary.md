# 成本-CPC 公式与名词口径

## 使用顺序

1. 在 CPC 参数模型中维护售价、目标 ACOS、预期 CVR、预算、SKU 计划占比、竞价安全系数和广告位加价。
2. 在成本利润模型中按每个售出 SKU 填写非广告成本。
3. 由成本表计算盈亏平衡 CPA/ACOS，再回传 CPC 模型。
4. 用目标 CPA 与盈亏平衡 CPA 中较低者约束理论最高 CPC。
5. 从活动明细反取平均起始竞价和最高基础竞价，计算压力与广告位风险。
6. 在测试副本中改变成本输入，验证整条公式链连续更新。

## 成本输入规则

| 输入 | 口径 |
|---|---|
| 售价 | 采用预期有效成交价；只在 CPC 参数模型维护 |
| 采购成本 | 单个售出 SKU 的总采购成本；两个装填写整套成本 |
| 汇率 | 人民币兑 1 美元 |
| 头程 | 分摊到一个售出 SKU 的美元金额 |
| FBA 配送费 | 当前尺寸重量对应的单件费用 |
| 佣金率 | 按品类和账户后台实际费率 |
| Coupon/促销 | 售价为原价时计折扣与费用；售价为折后价时仅计额外费用，避免重复 |
| 退货率 | 使用稳定期真实数据；新品可标记假设 |
| 单次退货损失 | 不可售损失、退回处理费、额外物流等合计 |
| 其他变动成本 | 包装、仓储分摊或其他每单发生的成本 |

采购、头程、FBA、佣金率，以及人民币采购场景下的汇率，任一为空时不计算盈亏平衡指标，不显示“安全”。Coupon/促销、退货和其他变动成本必须显式填 0 或标记假设，空白不代表 0。

## 核心公式

| 指标 | 公式 | 含义 |
|---|---|---|
| 目标 CPA | 售价 × 目标 ACOS | 目标 ACOS 下每单允许广告消耗 |
| 广告前贡献利润 | 售价－广告前总成本 | 广告投放前每单可用于广告与利润的金额 |
| 盈亏平衡 CPA | 广告前贡献利润 | 每单广告消耗的零利润边界 |
| 盈亏平衡 ACOS | 盈亏平衡 CPA ÷ 售价 | 广告消耗占售价的零利润边界 |
| CPA 安全差额 | 盈亏平衡 CPA－目标 CPA | 正数有缓冲，负数表示目标穿透盈亏线 |
| 理论最高 CPC | MAX(0, MIN(目标 CPA, 盈亏平衡 CPA) × 预期 CVR) | 目标与成本双约束下的点击上限 |
| CPC 压力 | 平均起始竞价 ÷ 理论最高 CPC | 起始竞价消耗模型上限的程度 |
| 预计 SKU 预算 | 活动预算 × SKU 计划占比 | 规划值，不是广告组硬预算 |
| 预计点击容量 | 预计 SKU 预算 ÷ 平均起始竞价 | 按规划竞价估算的点击数 |
| 位置后最高竞价 | 最高基础竞价 × (1＋广告位加价) | 仅适用于动态竞价“只降低”的计划上限 |

若使用动态竞价“提高和降低”，增加可编辑的动态上调上限，计算 `位置/动态后最高竞价 = 最高基础竞价 × (1＋广告位加价) × (1＋动态上调上限)`；基础竞价上限应反向除以两个乘数。

成本缺失时，可暂用 `目标 CPA × 预期 CVR` 计算探索期理论最高 CPC，但必须显示“成本待补全”，不得标记为利润安全。

## 风险分档

### CPC 压力

- ≤65%：有余量。
- >65% 且 ≤85%：接近上限。
- >85% 且 ≤100%：临界。
- >100%：超过上限。

### 位置后最高竞价

- ≤理论最高 CPC：安全。
- >理论最高 CPC 且 ≤理论最高 CPC × 110%：接近上限。
- >理论最高 CPC × 110%：超过上限。

### 成本安全

仅当以下条件同时成立时标记“安全”：

- 目标 ACOS ≤ 盈亏平衡 ACOS。
- 目标 CPA ≤ 盈亏平衡 CPA。
- 采购、头程、FBA 等最低成本输入完整。

盈亏平衡 CPA 小于等于 0 时，说明广告前已无贡献利润；理论最高 CPC 必须为 0，且不得显示“安全”。

## 名词解释最低集合

| 名词 | 必须说明 |
|---|---|
| 目标 ACOS | 阶段性广告目标，不等于盈亏线 |
| 盈亏平衡 ACOS | 利润约为 0 的边界，不是建议长期目标 |
| 预期 CVR | 订单÷点击；实际值下降会降低安全 CPC |
| 目标 CPA | 目标 ACOS 下每单允许广告费，不是单次点击成本 |
| 盈亏平衡 CPA | 成本角度每单最多可承受广告费 |
| CPA 安全差额 | 盈亏 CPA 与目标 CPA 的美元缓冲 |
| 理论最高 CPC | 模型上限，不是 Amazon 建议竞价 |
| 平均起始竞价 | 计划基础竞价平均值，不等于实际 CPC |
| CPC 压力 | 内部风险指标，不是官方字段或市场竞争度 |
| 竞价安全系数 | 为 CVR 和新品不确定性预留的折扣 |
| 最高基础竞价 | 叠加广告位调整前的最高计划竞价 |
| 广告位加价 | 百分比乘数，不是固定美元 |
| 动态上调上限 | “提高和降低”策略下平台可能追加的竞价乘数，必须作为可编辑参数 |
| 位置后最高竞价 | 潜在计划竞拍上限，不等于实际扣费 |
| 位置/动态后最高竞价 | 同时叠加广告位与动态上调后的潜在竞拍上限 |
| 预计 SKU 预算 | 活动共享预算的规划占比，不是后台硬限额 |
| 预计点击容量 | 预算÷竞价的估算，不是平台承诺 |
| 动态竞价－只降低 | Amazon 可下调基础竞价，不主动上调 |
| 否定精准 | 只拦截完全相同查询，适合迁词隔离 |
| 否定词组 | 拦截包含该词组的查询，只用于明确错配 |

动态上调上限应以站点和账户当日控制台为准，不在模型中写死；若还有受众、排期或其他竞价规则，继续纳入相应乘数。
