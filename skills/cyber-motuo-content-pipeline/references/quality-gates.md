# 内容生产质量关卡

| 关卡 | 通过标准 | 不通过处理 |
|---|---|---|
| AIHOT数据 | 至少一条路径返回真实条目；至少尝试三条独立路径 | 停止选题和写作 |
| 选题 | 三个栏目覆盖；HKR至少两项强；事件不重复 | 换题或减少篇数 |
| 来源 | 官方/原始来源可读；关键数据、日期、状态核验 | 删除未核实事实 |
| 亚马逊隐私 | 无真实产品、ASIN、SKU、Listing、图片和内部数据 | 匿名化并复查 |
| 写作 | 无虚构经历；观点有材料支撑；原创表达 | 返工 |
| 质检 | 事实、逻辑、版权、语气、隐私均通过 | 返工 |
| 微信草稿 | 官方授权接口写入成功并能回读确认 | 标记未写入 |
| 腾讯文档 | 目标目录和文档写入成功并能回读确认 | 标记待写入 |

任何一个硬性关卡失败，都不能将文章标记为“可发布”。
