# 微信公众号草稿箱

## 目标
把通过编辑质检的文章保存为公众号图文草稿。只创建草稿，不群发、不发布。

## 前置条件
- 用户已授权的微信公众号官方 API、可信连接器或受支持的正式操作通道。
- 已确认目标公众号身份。
- 标题、摘要、正文、封面、作者署名和来源链接齐全。
- 亚马逊隐私检查通过。

## 操作顺序
1. 读取当前公众号账号和草稿箱状态。
2. 确认图文消息编辑接口/连接器可用。
3. 按平台要求处理封面图、正文图片和富文本格式。
4. 创建草稿。
5. 读取返回的草稿 ID 或草稿列表，确认确实保存成功。
6. 将草稿 ID、标题、创建时间、状态记录到内容资产库。

## 绝对限制
- 不自动群发、不自动发布。
- 不在用户未确认的情况下更改公众号资料、菜单、自动回复或账号设置。
- 不将 AppSecret、Token、Cookie、二维码或登录凭据写入文章、日志或 Skill 文件。
- 不猜测 API 参数和接口；先读取官方文档。
- 不通过原始 CDP、隐藏接口、备用浏览器、脚本注入或其他方式绕过浏览器安全策略。
- 如果站点安全策略阻止访问，停止该路径；不得尝试间接规避。
- 没有可用授权通道时，只输出可复制图文稿，状态明确写为“未写入草稿箱”。

## 草稿字段
标题、摘要、作者（仅使用用户确认署名）、封面图、正文HTML/富文本、来源链接、栏目标签、隐私检查结果、质检状态。

## 最终反馈
必须说明是否真实创建成功、草稿ID（若返回）、是否能在草稿列表回读、未完成项目。不得把“文章已写好”说成“草稿已保存”。
