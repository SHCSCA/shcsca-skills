# 微信图文视觉包装

## 品牌视觉方向
- 年轻、活泼、有创造力。
- 像真实科技玩家，不像企业咨询公司。
- 轻赛博、潮流、友好、聪明、有趣。
- 避免过度冷峻、商务蓝金、机器人模板和廉价霓虹。

公众号名称/人物名称以用户最终确认版本为准；未确认时不要把「赛博墨拓」强行印在图片上。

## 每篇文章的视觉交付
1. 封面主图概念。
2. 封面标题与副标题建议。
3. 正文1–3张插图位置。
4. 每张图的用途、构图和生成提示词。
5. 图片与文章事实一致性检查。
6. 移动端裁切和文字可读性检查。

## 图片规则
- 封面突出一个核心视觉，不堆叠元素。
- 标题文字尽量后期排版，避免图像模型生成乱码。
- 产品、界面、数据图若为示意，必须标记“示意图”。
- 不把 AI 生成界面冒充真实产品截图。
- 亚马逊文章不得出现用户真实产品、品牌、ASIN、SKU、Listing或可识别产品图片。
- 数据图必须来自核验资料；虚构数据必须标注示意。

不为了配图而配图。每张图必须服务阅读理解。
