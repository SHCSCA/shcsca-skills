# Analysis Patterns

在扩展市场调研交付中，至少从以下 4 种分析模式里使用 3 种，并在报告中明确标注：

## 1. Demand Signal Triangulation（需求信号交叉验证）

用途：用 Review / 关键词 / 社区三维证据交叉判断需求是否真实存在。

适用：
- 功能真伪验证
- 新品方向判断
- 痛点是否值得做

输出要求：
- 明确每个方向的三维证据来源
- 标注强需求 / 中需求 / 弱需求 / 伪需求
- 不得只引用单一维度下结论

## 2. Top100 Structural Segmentation（Top100 结构拆解）

用途：对类目 Top100 做价格带、功能带、卖点带、评价带、品牌带分层，识别主流结构和异常机会点。

适用：
- 类目结构判断
- 是否存在薄供给带
- 价格带机会识别

输出要求：
- Top100 必须完整覆盖 100 条
- 至少拆出价格带、功能带、品牌带三个结构层
- 对每个结构层写“关键洞察”

## 3. Complaint-to-Opportunity Mapping（差评到机会映射）

用途：把差评痛点映射成可执行的品牌机会和产品方案，而不是只停留在抱怨归纳。

适用：
- 差评分析
- 功能升级建议
- 产品定义建议

输出要求：
- 使用 `痛点 → 品牌能力 → 产品方案` 三段式
- 痛点必须按属性维度归类
- 至少区分共性痛点和差异化机会

## 4. Supply Gap Prioritization（供需缺口优先级排序）

用途：对候选机会做优先级排序，避免平铺罗列。

评分模型：
- 市场规模：40%
- 技术可行性：30%
- 品牌匹配：30%

输出要求：
- 每个机会点给出三维评分
- 明确总分和排序
- 必须解释为什么排在前面

## 使用要求

- 每份扩展市场调研报告至少使用以上 4 种模式中的 3 种
- 在 Executive Summary 或方法说明中写明本次实际使用的模式
- 任一模式被引用时，都必须对应到具体数据表、样本池或结论段落
