# 分阶段工作流

## Phase 0：产品资料收集

收集产品、关键词、竞品、Review/VOC、参数与禁用表达。

同时补齐运营判断输入：

- A9 相关：核心关键词、点击/转化机会、价格带、评价、库存、配送、Featured Offer、账户健康风险
- COSMO 相关：人群、场景、任务、痛点、搭配关系、购买理由
- Rufus 相关：用户可能提出的购物问题、对比问题、安装/材质/尺寸/兼容性疑虑

资料不足时，只输出缺口清单，不进入图片需求稿。

## Phase 1：主图/副图参考图收集

必须要求用户上传主图/副图参考图。参考图可包括：

- 搜索结果页主图截图
- 竞品主图
- 竞品副图
- 功能图
- 场景图
- 尺寸图
- 安装图

此阶段只生成主图/副图需求稿，不生成A+。
主图/副图需求稿只能参考本阶段上传的主图/副图参考图，不得使用 A+横幅、A+模块图或 A+对比表作为参考。

主图/副图需求稿必须包含：

- 产品定位与运营机会
- 关键词意图、COSMO 场景意图、Rufus 问答承接
- Review/VOC 痛点到图片模块的映射
- 每张图对应的 A9 点击/转化目标

## Phase 2：主图/副图验收

等待用户明确确认。没有确认不得进入 A+。

## Phase 3：A+参考图收集

用户确认主图/副图后，要求上传A+参考图。
A+参考图必须独立提供，不能复用主图、竞品主图、竞品副图或搜索结果页截图。
进入本阶段后，后续交付必须基于主图/副图阶段已验收的原 Excel 工作簿继续补充，不得重新复制空模板。

## Phase 4：A+需求稿生成

基于 A+参考图生成A+模块需求。
A+需求稿只能参考本阶段上传的 A+参考图；A+参考图不足时先补图，不得借用主图/副图阶段图片。
必须在原主图/副图阶段工作簿内补充 `10_A+参考图`、`11_A+需求` 和相关检查项，并另存为新版本。不得生成只包含 A+内容的新工作簿。

A+模块必须承接主图/副图阶段未完全解释的深层问题，包括品牌信任、使用教育、对比表、包装清单、FAQ、售后/注意事项。每个模块要标注对应关键词意图、场景意图或 Rufus 问答。
