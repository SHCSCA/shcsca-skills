# 分阶段工作流

## Phase 0：产品资料

收集产品、变体、套装、参数、说明书、关键词、Review/VOC、竞品和禁用表达。

内部完成 A9 点击/转化、COSMO 场景/任务和 Rufus 问答判断，但不额外生成分析 Sheet。

资料不足时只输出缺口清单。

## Phase 1：主图/副图参考

读取或搜索：

- 搜索结果页/竞品主图
- 竞品副图、功能图、场景图
- 尺寸、安装、包装图

找图顺序：

1. 用户提供的同阶段参考图
2. Amazon 直接竞品
3. Amazon 其他同类商品
4. Walmart / Home Depot / Lowe’s / Target
5. 品牌官网或其他可信电商平台

当前竞品没有对应图型时继续全网补图，不允许空白交付。

只生成 `主图副图`，默认8行：

- 图1白底主图
- 图2–7核心卖点、操作、结构、参数、场景、步骤
- 图8包装/配件/变体

具体顺序按转化阻碍调整，不机械套固定卖点。

参考图默认使用远程 `IMAGE()` 公式。用户明确要求离线可见时才使用实体嵌图，并必须在目标 Excel/WPS 环境完成可视验证。

## Phase 2：验收

等待用户明确确认。

用户提出修改时，只修订 `主图副图`。未确认不得提前生成 A+。

修订时保留原顶部标题、元信息区、表头、列宽、行高和冻结窗格，不重新搭表导致样式丢失。

## Phase 3：A+参考

读取用户已提供的独立 A+参考；不足时按全网顺序补充最少所需：

- 品牌/顶部横幅
- 功能或互动模块
- 场景模块
- 对比表、Q&A、视频或技术规格

不得用主图、竞品主图或普通副图截图代替 A+参考。

## Phase 4：A+需求

打开已确认的主图/副图工作簿，增加 `A+需求` 并另存新版本。

普通 A+ 使用静态模块。

高级 A+：

- 默认5个模块，最多7个。
- 先建立 M1–M5 主模块总览。
- 优先评估功能轮播和场景轮播。
- 功能轮播使用2–5帧。
- 场景轮播使用2–6帧，模板默认5帧。
- 每帧仅表达一个功能或场景。
- 需要双端图时分别制作桌面与手机构图。
- 不适合轮播时改用 Full Image、Hotspots、Q&A、视频或技术规格。
- Comparison Table 2 仅用于2–3个真实可关联的同品牌产品/变体。

### 轮播拆分

凡使用轮播，主模块总览之后必须另设详细区：

1. 黄色模块说明分隔条。
2. 重复蓝色六列表头。
3. 每个 Panel 单独一行。
4. 每帧写清桌面/手机规格、画面要求、原生字段、参考图、Alt Text 和禁用。

不得只在 M2/M4 总览行写 `4 Panels` 后结束。

### 纯文本模块

Premium Q&A、技术规格等模块可以不上传图片，但 E列必须明确写 `原生文本模块｜无需上传图片`，不得留空。

最终文件只保留 `主图副图` 与 `A+需求` 两张执行页。

## Phase 5：质量检查

交付前检查：

- 所有需要视觉执行的行均有真实参考图。
- 远程 `IMAGE()` 公式地址为 HTTPS 图片文件地址。
- 远程图不显示时已替换来源。
- 顶部标题、元信息、表头、黄色轮播分隔条和交替卡片样式保留。
- 轮播帧已单独拆分。
- 公式错误扫描为0。
- 用户目标软件兼容性声明准确，不夸大“离线可见”或“打开即见”。
