# 分阶段工作流

## Phase 0：产品资料

收集产品、变体、套装、参数、说明书、关键词、Review/VOC、竞品和禁用表达。

内部完成 A9 点击/转化、COSMO 场景/任务和 Rufus 问答判断，但不额外生成分析 Sheet。

资料不足时只输出缺口清单。

## Phase 1：主图/副图参考

读取或要求用户提供：

- 搜索结果页/竞品主图
- 竞品副图、功能图、场景图
- 尺寸、安装、包装图

只生成 `主图副图`，默认8行：

- 图1白底主图
- 图2–7核心卖点、操作、结构、参数、场景、步骤
- 图8包装/配件/变体

具体顺序按转化阻碍调整，不机械套固定卖点。

## Phase 2：验收

等待用户明确确认。

用户提出修改时，只修订 `主图副图`。未确认不得提前生成 A+。

## Phase 3：A+参考

读取用户已提供的独立 A+参考；不足时只补要最少所需：

- 品牌/顶部横幅
- 功能或互动模块
- 场景模块
- 对比表、Q&A、视频或技术规格

不得用主图、竞品主图或副图截图代替 A+参考。

## Phase 4：A+需求

打开已确认的主图/副图工作簿，增加 `A+需求` 并另存新版本。

普通 A+ 使用静态模块。

高级 A+：

- 默认5个模块，最多7个。
- 优先评估功能轮播和场景轮播。
- 功能轮播使用2–5帧。
- 场景轮播使用2–6帧，模板默认5帧。
- 每帧仅表达一个功能或场景。
- 需要双端图时分别制作桌面与手机构图。
- 不适合轮播时改用 Full Image、Hotspots、Q&A、视频或技术规格。
- Comparison Table 2 仅用于2–3个真实可关联的同品牌产品/变体。

最终文件只保留 `主图副图` 与 `A+需求` 两张执行页。
