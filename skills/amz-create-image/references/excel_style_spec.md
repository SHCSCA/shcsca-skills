# 简版 Excel 样式规范

## 工作簿

- 主图/副图阶段：仅 `主图副图`
- 完整阶段：`主图副图`＋`A+需求`
- 关闭网格线，冻结执行表头
- 不增加后台分析、验收、合规或交付 Sheet

## 顶部结构

两张 Sheet 顶部必须保留统一样式：

1. 深蓝色合并标题栏，白色加粗标题。
2. 产品元信息区：产品名称、品牌、站点、方案/变体、图片规格、核心表达、统一禁用。
3. 标签单元格使用浅蓝底、加粗、居中。
4. 内容单元格白底、自动换行、顶部对齐。
5. 顶部不得出现大面积无用空白，也不得在修订时丢失标题栏和元信息样式。

## 六列版式

两张 Sheet 均使用六列卡片结构：

- A：编号
- B：适用范围/模块标签
- C：画面要求/原生文案
- D：英文断行文案/双端构图
- E：参考图
- F：备注、Alt Text、禁用

参考列宽约：

- A：10.67–16
- B：18.89–26
- C：38.89–52
- D：31.11–40
- E：28–36.44
- F：40–44

## 颜色

- 顶部标题：`#1F4E78` 或 `#4472C4`，白字
- 表头：`#2F75B5` 或 `#5B9BD5`，白字
- 标签：`#DDEBF7`
- 交替卡片：白色 / `#F4F9FC`
- 风险提示：`#FCE4E4`＋`#C00000`
- 输入/交付提示：`#FFF9E6` 或 `#FFF2CC`
- 轮播分隔条：`#FFF2CC`，深色加粗文字
- 边框：`#A9C2D3`

## 参考图列

- 默认使用远程 `IMAGE()` 公式。
- 参考图单元格必须有固定行高和足够列宽。
- 不使用透明占位图、空白绘图框或只写图片 URL。
- Q&A、技术规格等纯文本模块在 E列写 `原生文本模块｜无需上传图片`。
- 不新增本地路径、图片路径或附件路径列。
- 不使用 WPS `DISPIMG`。

## A+ 轮播排版

A+ Sheet 的顺序固定为：

1. 顶部元信息区
2. 主模块蓝色表头
3. M1–M5 主模块总览
4. 黄色 `M2 功能轮播详细拆分` 分隔条
5. 重复蓝色六列表头
6. M2 每帧一行
7. 黄色 `M4 场景轮播详细拆分` 分隔条
8. 重复蓝色六列表头
9. M4 每帧一行

轮播帧不得挤在同一单元格内。每帧行高应保证参考图、文案和 Alt Text 同时可读。

## 可读性

- 中文使用兼容中文的字体，英文可用 Arial
- 正文自动换行、垂直居中或顶部对齐
- 图片/模块行固定较高行高，保证远程图片可见
- 主图/副图每图一行，A+主模块每模块一行，轮播每帧一行
- 不使用大面积顶部空白、异常深色条或无意义合并区
- 涉及美国站尺寸/重量时，执行列优先展示 in/lb

## 修订原则

对现有工作簿改图、改文案或新增轮播时：

- 优先在原文件基础上修改，不重建导致样式丢失。
- 保留标题、元信息、表头、分隔条、列宽、行高和冻结窗格。
- 修订后必须检查两张 Sheet 的顶部样式一致性。
