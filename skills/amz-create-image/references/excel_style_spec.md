# 简版 Excel 样式规范

## 工作簿

- 主图/副图阶段：仅 `主图副图`
- 完整阶段：`主图副图`＋`A+需求`
- 关闭网格线，冻结第8行表头
- 不增加后台分析、验收、合规或交付 Sheet

## 六列版式

两张 Sheet 均使用六列卡片结构：

- A：编号
- B：适用范围/模块标签
- C：画面要求/原生文案
- D：英文断行文案/双端构图
- E：参考图/交付尺寸
- F：备注、Alt Text、禁用

参考列宽约：

- A：10.67
- B：18.89
- C：38.89
- D：31.11
- E：36.44
- F：40

## 颜色

- 标题：`#4472C4` 白字
- 表头：`#5B9BD5` 白字
- 标签：`#DDEBF7`
- 交替卡片：白色 / `#F4F9FC`
- 风险提示：`#FCE4E4`＋`#C00000`
- 输入/交付提示：`#FFF9E6` 或 `#FFF2CC`
- 边框：`#A9C2D3`

## 可读性

- 中文使用兼容中文的字体，英文可用 Arial
- 正文自动换行、垂直居中
- 图片/模块行固定较高行高，保证参考图可见
- 参考图置于对应行，不另建图片索引 Sheet
- 主图/副图每图一行，A+每模块/每帧一行
- 不使用大面积顶部空白、异常深色条或无意义合并区
- 不新增本地路径、图片路径或附件路径列
- 不使用 WPS `DISPIMG`
- 涉及美国站尺寸/重量时，执行列优先展示 in/lb
