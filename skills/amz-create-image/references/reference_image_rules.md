# 参考图规则

## 阶段隔离

- 主图/副图只使用搜索结果页、竞品主图、副图、功能图、场景图、尺寸/安装/包装图。
- A+只使用品牌横幅、A+功能模块、场景模块、对比表等独立 A+参考。
- 主图/副图不得借用 A+参考图。
- A+不得借用主图、竞品主图、竞品副图或搜索结果页截图。
- 参考类型不匹配时继续补图，不迁就使用。

## 同行绑定

不再建立独立参考图索引 Sheet。

每张需求图、A+主模块或轮播帧必须在同一行完成：

- 参考编号
- 参考图片
- 参考点
- 来源网址
- 禁止照抄点

推荐编号：

- `MAIN_REF_01`
- `SEC_REF_01` 至 `SEC_REF_08`
- `APLUS_REF_01` 至 `APLUS_REF_20`

## 覆盖率

- 每个需要视觉执行的主图、副图、A+主模块和轮播帧都必须有真实参考图。
- 原生 Q&A、技术规格等纯文本模块无需图片，但 E列必须明确写：`原生文本模块｜无需上传图片`。
- 不得留下空白图片框、透明占位图或只写“见附件”。
- 当前竞品没有对应图型时，必须继续全网搜索。

## 找图顺序

1. 用户提供的同阶段参考图
2. Amazon 直接竞品
3. Amazon 其他同类商品
4. Walmart / Home Depot / Lowe’s / Target
5. 品牌官网或其他可信电商平台

参考图必须与当前任务匹配：

- 主图参考主图
- 场景图参考场景图
- 尺寸图参考尺寸图
- 安装图参考安装图
- 包装图参考包装图
- A+横幅参考A+横幅
- 功能轮播参考功能轮播
- 场景轮播参考场景轮播

## 默认交付：远程图片公式

E列默认使用 Excel `IMAGE()` 公式：

```excel
=IMAGE("https://...","APLUS_REF_01",0)
```

要求：

- 地址必须是可直接访问的 HTTPS 图片文件地址，不是商品详情页 URL。
- 使用真实图片，不使用搜索结果缩略图占位。
- 用户在 Excel/WPS 中允许外部内容后显示。
- 远程地址失效、被拦截或不显示时，应替换为新的可访问来源。
- 不使用 WPS `DISPIMG`，避免普通 Excel 出现 `#NAME?`。
- 不承诺断网可见。

## 可选交付：实体嵌图

仅当用户明确要求离线可见或禁止外链时使用。

要求：

- 必须把 JPG/PNG 二进制写入工作簿，而不是添加外链绘图对象。
- 必须在用户目标 Excel/WPS 环境完成可视验证。
- 未经目标软件验证，不得声称“直接打开可见”。
- 若目标软件不显示嵌入图，应立即回退到远程 `IMAGE()` 方案，不继续反复交付空白图框。

## 轮播参考图

凡出现功能轮播或场景轮播：

- 主模块区可以有一张轮播整体节奏参考图。
- 下方详细拆分区的每一帧必须另有对应参考图。
- 不得让4帧共用一个空白图片框。
- 轮播参考图应与该帧任务一致，不只因为来源相同就重复使用。

## 禁止照抄

参考图只学习：

- 信息层级
- 构图逻辑
- 主体比例
- 留白与原生字段配合
- 轮播节奏和帧间差异

不得复制：

- 竞品 Logo、品牌名
- 竞品原图、人物和场景
- 竞品文案、参数和图标
- 竞品完整配色与版式
