# 参考图规则

## 阶段隔离

- 主图/副图只使用搜索结果页、竞品主图、副图、功能图、场景图、尺寸/安装/包装图。
- A+只使用品牌横幅、A+功能模块、场景模块、对比表等独立 A+参考。
- 主图/副图不得借用 A+参考图。
- A+不得借用主图、竞品主图、竞品副图或搜索结果页截图。
- 参考类型不匹配时先补图，不迁就使用。

## 同行绑定

不再建立独立参考图索引 Sheet。

每张需求图或 A+模块在同一行完成：

- 参考编号
- 嵌入参考图片
- 参考点
- 禁止照抄点

推荐编号：

- `MAIN_REF_01`
- `SEC_REF_01` 至 `SEC_REF_08`
- `APLUS_REF_01` 至 `APLUS_REF_07`

## 嵌入要求

- 图片必须真正嵌入 Excel。
- 不得只写 ASIN、竞品名称、图片路径、`见附件` 或 `参考上图`。
- 不得使用 WPS `DISPIMG`，避免普通 Excel 出现 `#NAME?`。
- 生成时必须替换模板中的“嵌入参考图”占位文字。

## 禁止照抄

参考图只学习：

- 信息层级
- 构图逻辑
- 主体比例
- 留白与原生字段配合

不得复制：

- 竞品 Logo、品牌名
- 竞品原图、人物和场景
- 竞品文案、参数和图标
- 竞品完整配色与版式
