# 参考图片规则

1. Excel 中必须直接嵌入参考图片。
2. 不能只写 ASIN、图号或文字描述。
3. 参考图必须按阶段隔离：
   - 主图/副图需求稿只能参考用户给到的主图/副图参考图。
   - A+需求稿只能参考用户给到的 A+参考图。
   - 主图不得参考 A+图；A+不得参考主图、竞品主图、竞品副图或搜索结果页图。
   - 若用户只给了错误阶段的参考图，必须要求补充正确阶段参考图。
4. 参考图必须配套说明：
   - 参考点
   - 禁止照抄点
   - 适用图片编号
5. 需求表中的参考图编号、参考图片、参考点必须一一对应：
   - `06_主图需求`、`07_副图需求` 只能引用 `08_主图副图参考图` 的同一编号行。
   - `11_A+需求` 只能引用 `10_A+参考图` 的同一编号行。
   - 多个编号时，图片和参考点按编号顺序逐项对应；不能把一个编号的图片配另一个编号的参考点。
6. 不新增本地路径、图片路径、附件路径等路径列；以嵌入图片和参考编号为准。
7. 推荐编号：
   - `MAIN_REF_01`：搜索结果页主图
   - `MAIN_REF_02`：竞品主图
   - `SEC_REF_01`：竞品副图/功能图
   - `SEC_REF_02`：场景图/尺寸图/安装图
   - `APLUS_REF_01`：A+顶部横幅
   - `APLUS_REF_02`：A+功能模块
   - `APLUS_REF_03`：A+场景模块/对比表
8. 参考图不能用于最终图直接复用。
9. 若没有同阶段参考图，先要求用户补充，不得生成最终需求稿。
