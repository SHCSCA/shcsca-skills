- [ ] 当前阶段只交付 `主图副图`

- [ ] 每行均有图号、适用链接、画面要求、断行文案、参考图、备注/禁用

- [ ] 不含本地路径、`见附件` 或 `DISPIMG`
- [ ] 参数、部位、动作和配件均已确认
