# 交付检查清单

## 后台判断

- [ ] 已确认产品、站点、品牌、变体与包装数量
- [ ] 已确认核心卖点、参数来源、说明书限制与禁用表达
- [ ] 已分析关键词、A9点击/转化、COSMO场景和Rufus问答
- [ ] 已将Review/VOC、差评和退货疑虑转成图片策略
- [ ] 未把后台分析拆成多张交付 Sheet

## 主图/副图

- [ ] 当前阶段只交付 `主图副图`
- [ ] 默认8行，按产品复杂度控制在7–9行
- [ ] 每行均有图号、适用链接、画面要求、断行文案、参考图、备注/禁用
- [ ] 图1和包装图数量与变体链接一致
- [ ] 共用图和分别出图已标清
- [ ] 同阶段参考图已嵌入对应行
- [ ] 不含路径、`见附件` 或 `DISPIMG`
- [ ] 参数、部位、动作和配件均已确认
- [ ] 美国站尺寸/重量已按需转换为 in/lb
- [ ] 用户已明确验收通过后才进入 A+

## A+

- [ ] 基于已确认的原工作簿继续补充
- [ ] 最终仅有 `主图副图` 与 `A+需求`
- [ ] A+只使用独立 A+参考图
- [ ] 普通/高级 A+类型已确认
- [ ] 高级 A+默认5模块，未超过7模块
- [ ] 功能轮播为2–5帧，每帧只讲一个功能
- [ ] 场景轮播为2–6帧，每帧只讲一个场景
- [ ] 内容不足时未强制双轮播
- [ ] 需要双端图时桌面与手机已分别构图
- [ ] 原生字段字符限制已校验
- [ ] 对比表只关联真实同品牌产品/变体
- [ ] 不足2个产品时已改用Q&A、视频或技术规格
- [ ] Alt Text、禁用表达和发布前事实确认已写清

## 文件质量

- [ ] 参考图真正嵌入，不是文字占位
- [ ] 中文、英文、尺寸和文案没有截断
- [ ] 色彩、列宽、行高与模板一致
- [ ] 无公式错误、空白 Sheet、异常色条或大片无用空白
- [ ] 所有 Sheet 已完成至少一次可视检查
