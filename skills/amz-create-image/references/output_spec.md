# 输出规范

本文件是 `amz-create-image` 的交付契约。生成需求稿前必须先判断阶段；不能把阻断状态、主图/副图稿、A+稿混在一次输出里。

## 输出物类型

按阶段只输出一种结果：

- 阻断输出：资料缺口清单、参考图缺口清单、验收等待提示。
- 主图/副图阶段 Excel：基于模板生成主图、副图和对应参考图需求稿。
- A+阶段 Excel：基于已验收的主图/副图 Excel 继续补充 A+，另存新版本。
- 修订版 Excel：用户提出修改意见时，在原阶段文件上修订，不跨阶段补内容。

## 阻断输出

遇到以下情况不得生成 Excel：

- 产品资料不足：只列 `缺失信息`、`为什么需要`、`示例格式`。
- 未上传主图/副图参考图：只要求补充主图/副图参考图。
- 主图/副图未验收通过：只等待确认或修改意见，不要求 A+参考图。
- 未上传 A+参考图或 A+参考图不足：只要求补充 A+参考图。
- 参考图阶段不匹配：说明哪些图片不能用，并要求补正确阶段参考图。

阻断输出必须简短、可执行；不得虚构参数补齐。

## 主图/副图阶段输出

主图/副图阶段只能生成主图/副图需求稿，不得输出完整 A+需求稿。

必须包含：

- 产品定位
- 运营机会判断：点击机会、转化阻碍、竞品空缺、合规风险
- 竞品拆解
- 关键词意图
- COSMO 场景/任务/痛点意图
- Rufus 问答承接清单
- Review/VOC
- Review/VOC 到图片模块映射
- 主图方案
- 副图逐张需求
- 图片数量规则：正常 7张，最多9张，按需求拓展
- 图片序位、数量规则、是否轮播
- 尺寸/重量单位换算：`cm × 0.3937 = in`，`kg × 2.20462 = lb`，输出美制 `in/lb` 并保留原始值核对
- 主图/副图参考图索引
- 主图/副图验收表

不得使用 A+参考图作为主图/副图参考依据。

## A+阶段输出

必须在主图/副图验收通过后输出，且必须以主图/副图阶段已验收的 Excel 为源文件继续补充。

必须包含：

- A+参考图索引
- A+运营目标：品牌信任、场景教育、对比证明、FAQ/注意事项
- A+模块需求
- 每个 A+模块对应的关键词意图、COSMO 意图或 Rufus 问答
- A+断行文案
- A+版式尺寸
- A+手机端尺寸/裁切：必须考虑 600×450，不只写 1464×600
- A+数量规则：一般 5张/5个模块，按需求拓展
- 模块序位、数量规则、是否轮播
- A+尺寸/重量参数换算：若输入为 `cm/kg`，必须输出 `in/lb`；换算系数为 `cm × 0.3937 = in`、`kg × 2.20462 = lb`
- A+验收标准

A+阶段不得使用主图、竞品主图、竞品副图或搜索结果页截图作为 A+参考依据；只能使用用户上传的 A+参考图。输出文件必须保留已确认的主图/副图内容，不得只包含 A+内容。

## Excel 工作簿规范

必须使用 `templates/amz-create-image_workbook.xlsx` 或基于已验收版本继续补充。不得交付只含散文说明的 Markdown 当作最终需求稿。

## 参考图匹配输出

- 主图/副图需求行只从 `08_主图副图参考图` 取参考图编号、参考图片和参考点。
- A+需求行只从 `10_A+参考图` 取参考图编号、参考图片和参考点。
- 同一需求行中的参考图编号、参考图片、参考点/禁止照抄必须一一对应，不能混用不同编号的图片和描述。
- 不输出本地路径、图片路径或附件路径列。

## 最终回复

生成 Excel 后，最终回复只包含：

- 已生成或已修订的阶段名称
- 1-3 条关键变更摘要
- `.xlsx` 文件链接
- 下一步等待项：例如“请确认主图/副图是否通过；通过后再进入 A+”

不得在最终回复里粘贴整份需求稿正文；需求稿正文必须在 Excel 内。

## 文件命名

主图/副图阶段：

```text
[品牌]_[产品]_主图副图需求稿_v1.xlsx
```

A+阶段：

```text
[品牌]_[产品]_主图副图_A+补充需求稿_v2.xlsx
```

完整阶段：

```text
[品牌]_[产品]_主图副图_A+完整需求稿_vFinal.xlsx
```

## 质量门禁

交付前必须确认：

- Excel 可打开，关键 sheet 不为空。
- 参考图片直接嵌入，不是路径、ASIN、图号或“见附件”。
- 参考图编号、参考图片、参考点来自同一索引行。
- 主图/副图未引用 A+参考图；A+未引用主图/副图参考图。
- 文案均为断行版，不是整段英文。
- 主图/副图正常 7张、最多9张；A+一般 5张/5个模块，拓展理由明确。
- A+同时考虑桌面端尺寸和手机端 600×450。
- cm/kg 已换算为 in/lb，并保留原始值核对。
- 不含 `本地路径`、`图片路径`、`附件路径` 列。
- 不含上线复盘表。

## 不得交付

- 资料不足却生成完整需求稿。
- 主图/副图未验收却生成 A+。
- A+阶段从空模板新建，导致缺少已确认主图/副图内容。
- 用错误阶段参考图迁就生成。
- 只输出 Markdown/聊天正文，不生成 Excel 文件。
- 生成只含 A+内容、缺少主图/副图内容的 Excel。
- 生成带本地图片路径但没有嵌入图片的 Excel。
