# 输出规范

## 主图/副图阶段输出

- 产品定位
- 运营机会判断：点击机会、转化阻碍、竞品空缺、合规风险
- 竞品拆解
- 关键词意图
- COSMO 场景/任务/痛点意图
- Rufus 问答承接清单
- Review/VOC
- Review/VOC 到图片模块映射
- 主图方案
- 副图逐张需求
- 图片数量规则：正常 7张，最多9张，按需求拓展
- 图片序位、数量规则、是否轮播
- 尺寸/重量单位换算：`cm × 0.3937 = in`，`kg × 2.20462 = lb`，输出美制 `in/lb` 并保留原始值核对
- 主图/副图参考图索引
- 主图/副图验收表

不得输出完整 A+需求稿。
不得使用 A+参考图作为主图/副图参考依据。

## A+阶段输出

必须在主图/副图验收通过后输出：

- A+参考图索引
- A+运营目标：品牌信任、场景教育、对比证明、FAQ/注意事项
- A+模块需求
- 每个 A+模块对应的关键词意图、COSMO 意图或 Rufus 问答
- A+断行文案
- A+版式尺寸
- A+手机端尺寸/裁切：必须考虑 600×450，不只写 1464×600
- A+数量规则：一般 5张/5个模块，按需求拓展
- 模块序位、数量规则、是否轮播
- A+尺寸/重量参数换算：若输入为 `cm/kg`，必须输出 `in/lb`；换算系数为 `cm × 0.3937 = in`、`kg × 2.20462 = lb`
- A+验收标准

A+阶段不得使用主图、竞品主图、竞品副图或搜索结果页截图作为 A+参考依据；只能使用用户上传的 A+参考图。
A+阶段必须以主图/副图阶段已验收的 Excel 为源文件继续补充，并另存为新版本。输出文件必须保留已确认的主图/副图内容，不得只包含 A+内容。

## 参考图匹配输出

- 主图/副图需求行只从 `08_主图副图参考图` 取参考图编号、参考图片和参考点。
- A+需求行只从 `10_A+参考图` 取参考图编号、参考图片和参考点。
- 同一需求行中的参考图编号、参考图片、参考点/禁止照抄必须一一对应，不能混用不同编号的图片和描述。
- 不输出本地路径、图片路径或附件路径列。
