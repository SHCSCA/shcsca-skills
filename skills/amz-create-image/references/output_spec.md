# 输出规范

## 主图/副图阶段输出

- 产品定位
- 运营机会判断：点击机会、转化阻碍、竞品空缺、合规风险
- 竞品拆解
- 关键词意图
- COSMO 场景/任务/痛点意图
- Rufus 问答承接清单
- Review/VOC
- Review/VOC 到图片模块映射
- 主图方案
- 副图逐张需求
- 主图/副图参考图索引
- 主图/副图验收表

不得输出完整 A+需求稿。
不得使用 A+参考图作为主图/副图参考依据。

## A+阶段输出

必须在主图/副图验收通过后输出：

- A+参考图索引
- A+运营目标：品牌信任、场景教育、对比证明、FAQ/注意事项
- A+模块需求
- 每个 A+模块对应的关键词意图、COSMO 意图或 Rufus 问答
- A+断行文案
- A+版式尺寸
- A+验收标准

A+阶段不得使用主图、竞品主图、竞品副图或搜索结果页截图作为 A+参考依据；只能使用用户上传的 A+参考图。
A+阶段必须以主图/副图阶段已验收的 Excel 为源文件继续补充，并另存为新版本。输出文件必须保留已确认的主图/副图内容，不得只包含 A+内容。
