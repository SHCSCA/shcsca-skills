# 简版输出规范

## 1. 输出物类型

每个阶段只输出一种结果：

- 阻断输出：资料缺口、参考图缺口或验收等待。
- 主图/副图 Excel：只含 `主图副图` 执行页。
- A+ Excel：在已确认文件中增加 `A+需求`，最终共2张执行页。
- 修订版 Excel：只修改用户要求的阶段，不擅自扩展范围。

## 2. 阻断输出

以下情况不得猜测后生成：

- 产品名称、变体、包装数量或关键参数不清楚。
- 主图/副图阶段没有可用的同阶段参考图。
- 主图/副图尚未通过却要求自动进入 A+。
- A+阶段没有可用的 A+参考图。
- 参考图与当前阶段不匹配。

缺口清单只写：

- 缺失信息
- 为什么需要
- 用户可直接回复的示例格式

## 3. 主图/副图阶段

使用 `templates/amz-create-image_workbook.xlsx` 的 `主图副图` 版式，并遵循 `templates/amz-create-image_workbook_layout_v2.md`。

默认 1张主图＋7张副图，共8行；可按产品复杂度调整为7–9行。

固定六列：

| 列 | 字段 |
|---|---|
| A | 图号 |
| B | 适用链接 |
| C | 画面／拍摄要求 |
| D | 英文文案（断行版） |
| E | 参考图 |
| F | 备注／禁用 |

顶部只保留：

- 产品名称
- 品牌
- 站点
- 款式/变体
- 图片规格
- 出图规则
- 核心卖点
- 统一禁用

不得增加竞品地图、关键词意图、Review、运营映射、验收、合规、交付检查等独立 Sheet。相关判断直接融入每张图片的画面、文案和备注。

主图/副图阶段不得填入产品化的 A+模块内容。

## 4. A+阶段

必须基于已确认的主图/副图文件继续编辑，另存新版本。

最终仅保留：

- `主图副图`
- `A+需求`

`A+需求` 固定六列：

| 列 | 字段 |
|---|---|
| A | 模块/帧 |
| B | 适用链接、模块类型或标签 |
| C | 画面／构图要求或原生文案 |
| D | 英文文案（断行版）或双端构图 |
| E | A+参考图 |
| F | 备注、Alt Text 与禁用 |

### 主模块区

高级 A+ 先列出 M1–M5 主模块总览：

- M1 品牌首屏
- M2 功能轮播概要
- M3 使用教育
- M4 场景轮播概要
- M5 对比表、Q&A、视频或技术规格

高级 A+ 允许最多7个模块；默认保留视频/Q&A扩展空间，不为了凑数量强行加模块。

### 轮播详细区

凡出现轮播，必须在主模块区下方另设详细分区：

1. 黄色分隔条，写清模块名称、帧数、桌面/手机出图要求。
2. 重复蓝色六列表头。
3. 每帧单独一行。
4. 每帧分别写画面、原生字段、参考图、Alt Text 与禁用。
5. 桌面 `1464 × 600` 与手机 `600 × 450` 分别构图。

不得：

- 把多个轮播帧写在同一单元格中。
- 只写 `4 Panels` 而没有每帧执行要求。
- 省略轮播帧的参考图。

## 5. 参考图输出

### 覆盖要求

- 每个需要视觉执行的主图、副图、A+主模块和轮播帧都必须有真实参考图。
- 原生 Q&A、技术规格等纯文本模块，E列必须写 `原生文本模块｜无需上传图片`，不得留空。
- 当前竞品缺图时必须全网补图，不允许空白交付。

### 默认模式：远程图片公式

E列默认使用：

```excel
=IMAGE("https://...","REF_01",0)
```

要求：

- 使用可直接访问的 HTTPS 图片地址。
- 用户在 Excel/WPS 中允许外部内容后显示。
- 同一行 F列写参考编号、参考点、来源网址和禁止照抄点。
- 远程图片打不开时更换来源，不得静默留空。
- 不使用 WPS `DISPIMG`。
- 不承诺断网可见。

### 可选模式：实体嵌图

仅当用户明确要求离线可见时使用。必须在用户目标 Excel/WPS 环境完成可视验证；未验证时不得声称“直接打开即可看到”。

### 找图顺序

1. 用户提供的同阶段参考图
2. Amazon 直接竞品
3. Amazon 其他同类商品
4. Walmart / Home Depot / Lowe’s / Target
5. 品牌官网或其他可信电商平台

主图/副图与 A+参考图严格分阶段；参考图必须与当前图型匹配。

## 6. 文案输出

- 图片内文案必须是断行版。
- 区分主标题、副标题、子项和注释。
- 高级 A+ 原生字段文案必须标注字符上限。
- 每帧只表达一个购买理由或一个场景。
- 不把原生字段长文案重复烙在图片内。

## 7. 样式保持

修订现有工作簿时必须保留：

- 顶部深蓝标题栏
- 产品元信息区
- 蓝色六列表头
- 浅蓝交替卡片
- 黄色轮播分隔条
- 列宽、行高、冻结窗格和关闭网格线设置

不得因为改图或增补轮播导致顶部样式丢失。

## 8. 文件命名

```text
[品牌]_[产品]_主图副图需求稿_v1.xlsx
[品牌]_[产品]_主图副图_A+需求稿_v2.xlsx
```

修订版递增版本号，并在文件名中体现关键修订，例如：

```text
[品牌]_[产品]_主图副图_A+需求稿_v3_远程图片版.xlsx
```

## 9. 最终回复

最终回复只包含：

- 已完成的阶段
- 1–3条关键变化
- `.xlsx` 文件链接
- 下一步等待项

不在聊天中粘贴整份需求稿。

## 10. 质量门禁

交付前确认：

- Sheet 数符合阶段：1张或2张。
- 主图/副图7–9行；默认8行。
- A+主模块和轮播详细区完整且不重复。
- 产品、变体、包装数量和适用链接一致。
- 每个应有参考图的行都有远程 `IMAGE()` 公式或已验证实体图片。
- Q&A等纯文本模块已明确标注无需图片。
- 文案为断行版，且字符限制正确。
- 手机与桌面需要双端图时已分别构图。
- cm/kg 已按需换算为 in/lb。
- 无未确认参数、错误部位、危险动作或疗效宣称。
- 无公式错误、空白 Sheet、路径列或 WPS 专用图片公式。
- 顶部样式、表头、分隔条、列宽和行高均保留。
- 所有 Sheet 已完成至少一次结构与可视检查。
