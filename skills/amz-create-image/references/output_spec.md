# 简版输出规范

## 1. 输出物类型

每个阶段只输出一种结果：

- 阻断输出：资料缺口、参考图缺口或验收等待。
- 主图/副图 Excel：只含 `主图副图` 执行页。
- A+ Excel：在已确认文件中增加 `A+需求`，最终共2张执行页。
- 修订版 Excel：只修改用户要求的阶段，不擅自扩展范围。

## 2. 阻断输出

以下情况不得猜测后生成：

- 产品名称、变体、包装数量或关键参数不清楚。
- 主图/副图阶段没有可用的同阶段参考图。
- 主图/副图尚未通过却要求自动进入 A+。
- A+阶段没有可用的 A+参考图。
- 参考图与当前阶段不匹配。

缺口清单只写：

- 缺失信息
- 为什么需要
- 用户可直接回复的示例格式

## 3. 主图/副图阶段

使用 `templates/amz-create-image_workbook.xlsx` 的 `主图副图` 版式。

默认 1张主图＋7张副图，共8行；可按产品复杂度调整为7–9行。

固定六列：

| 列 | 字段 |
|---|---|
| A | 图号 |
| B | 适用链接 |
| C | 画面／拍摄要求 |
| D | 英文文案（断行版） |
| E | 参考图 |
| F | 备注／禁用 |

顶部只保留：

- 产品名称
- 品牌
- 站点
- 款式/变体
- 图片规格
- 出图规则
- 核心卖点
- 统一禁用

不得增加竞品地图、关键词意图、Review、运营映射、验收、合规、交付检查等独立 Sheet。相关判断直接融入每张图片的画面、文案和备注。

主图/副图阶段不得填入产品化的 A+模块内容。

## 4. A+阶段

必须基于已确认的主图/副图文件继续编辑，另存新版本。

最终仅保留：

- `主图副图`
- `A+需求`

`A+需求` 固定六列：

| 列 | 字段 |
|---|---|
| A | 模块/帧 |
| B | 适用链接、模块类型或标签 |
| C | 画面／构图要求或原生文案 |
| D | 英文文案（断行版）或双端构图 |
| E | A+参考图或交付尺寸 |
| F | 备注、Alt Text 与禁用 |

高级 A+ 默认结构：

- 5个主模块
- 功能轮播明细
- 场景轮播明细
- 发布前事实确认
- 官方规范链接

高级 A+ 允许最多7个模块；默认保留视频/Q&A扩展空间，不为了凑数量强行加模块。

## 5. 参考图输出

- 参考图片直接嵌入对应行。
- 同一行写参考编号、参考点和禁止照抄点。
- 不新增本地路径、附件路径或图片路径列。
- 不使用 WPS `DISPIMG`、`#NAME?` 或只写“见附件”。
- 主图/副图与 A+参考图严格分阶段。

## 6. 文案输出

- 图片内文案必须是断行版。
- 区分主标题、副标题、子项和注释。
- 高级 A+ 原生字段文案必须标注字符上限。
- 每帧只表达一个购买理由或一个场景。
- 不把原生字段长文案重复烙在图片内。

## 7. 文件命名

```text
[品牌]_[产品]_主图副图需求稿_v1.xlsx
[品牌]_[产品]_主图副图_A+需求稿_v2.xlsx
```

## 8. 最终回复

最终回复只包含：

- 已完成的阶段
- 1–3条关键变化
- `.xlsx` 文件链接
- 下一步等待项

不在聊天中粘贴整份需求稿。

## 9. 质量门禁

交付前确认：

- Sheet 数符合阶段：1张或2张。
- 主图/副图7–9行；默认8行。
- A+主模块和轮播明细完整且不重复。
- 产品、变体、包装数量和适用链接一致。
- 参考图已真正嵌入。
- 文案为断行版，且字符限制正确。
- 手机与桌面需要双端图时已分别构图。
- cm/kg 已按需换算为 in/lb。
- 无未确认参数、错误部位、危险动作或疗效宣称。
- 无公式错误、空白 Sheet、路径列或 WPS 专用图片公式。
- 所有 Sheet 已完成可视检查。
