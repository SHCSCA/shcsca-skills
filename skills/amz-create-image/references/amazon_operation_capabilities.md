# Amazon 运营与算法能力定义

本文件定义 `amz-create-image` 在生成主图、副图、A+需求稿时必须具备的运营判断能力。目标不是讲算法概念，而是把运营判断落到图片模块、文案断行和美工执行要求。

## 核心运营能力

| 能力 | 判断问题 | 图片需求稿落点 |
| --- | --- | --- |
| 选品与定位 | 产品卖给谁，解决什么问题，价格带是否合理 | 产品定位、主图点击点、A+首屏品牌/场景 |
| 关键词意图 | 用户用什么词搜索，搜索词背后的任务是什么 | `04_关键词意图`、主图标题、副图模块顺序 |
| 转化率优化 | 用户点击后还担心什么，为什么不下单 | 副图参数、安装、对比、场景、QA 式说明 |
| 广告协同 | 哪些广告词有曝光/点击/转化，哪些词浪费 | 将高价值词映射到图文，不为低相关词做图 |
| Review/VOC 洞察 | 好评为什么买，差评为什么退，Q&A 问什么 | `05_评论痛点`、痛点回应图、禁用夸张承诺 |
| 竞品拆解 | 竞品赢在哪里，哪里拥挤/夸大/没讲清 | 参考点/禁止照抄、差异化对比图 |
| 供应链意识 | 图片承诺是否被真实产品、配件、认证支持 | 合规检查、参数来源、禁用表达 |

## A9 搜索排序理解

在本 Skill 中，A9 作为卖家侧对 Amazon 搜索排序逻辑的简称使用，不得声称掌握 Amazon 未公开公式。

图片需求稿需要服务以下可运营信号：

- 相关性：标题、卖点、图片、属性、后台词与搜索词是否匹配
- 点击：搜索结果缩略图是否一眼看懂产品、套装、差异和价格带
- 转化：副图和 A+是否降低疑虑并支撑下单
- 表现：销量、评价、价格、配送、库存、Featured Offer、账户健康等综合因素

落地要求：

- 主图优先提升点击和品类识别，不塞长文案
- 副图优先解释影响转化的功能、参数、使用方式和疑虑
- A+优先增强品牌信任、场景教育和产品体系理解

## COSMO 意图理解

COSMO 按 Amazon Science 公开方向理解为电商常识知识和用户意图理解能力。它提醒运营不要只做关键词匹配，而要表达“用户为什么需要这个产品”。

每个图片模块尽量绑定一种意图：

- 人群意图：for renters、for parents、for DIY users、for pet owners
- 场景意图：bedroom、kitchen、garage、travel、office、gift
- 任务意图：install、clean、organize、protect、decorate、replace
- 痛点意图：no drilling、easy to clean、less clutter、fit small spaces
- 搭配意图：camera + case、lamp + remote、shelf + organizer

注意：意图表达必须基于真实产品能力；不能为了迎合场景而虚构功能。

## Rufus 对话式购物理解

Rufus 会把用户问题转成购物建议、对比和推荐。图片需求稿要让产品内容能被自然语言理解。

常见 Rufus 问题类型：

- 这个产品适合什么人/什么场景？
- 和普通款、竞品、旧款有什么区别？
- 安装、清洁、维护是否麻烦？
- 尺寸、材质、配件、兼容性是否匹配我的需求？
- Review 里大家最满意和最不满意什么？
- 买之前需要注意什么？

落地要求：

- 用短句表达真实利益点，避免只写关键词堆叠
- 图片模块标题要像答案，不像搜索词列表
- 重要参数要有来源，未确认参数进入缺口清单
- 对比图只能比较真实差异，不攻击具体品牌

## 图片模块映射规则

| 图片位置 | 优先能力 | 输出要求 |
| --- | --- | --- |
| 主图 | A9 点击、品类识别 | 产品完整、主体清晰、套装/核心差异可识别 |
| 副图 1-2 | 转化疑虑、核心功能 | 先讲最影响下单的功能和痛点 |
| 副图 3-5 | 参数、安装、使用场景 | 参数真实、步骤清楚、场景不误导 |
| 副图 6-8 | 对比、信任、多场景 | 对比克制，不照抄竞品，不虚构优势 |
| A+首屏 | 品牌和场景心智 | 让用户知道品牌、产品定位和核心价值 |
| A+中段 | 教育和证明 | 结构、材质、使用方式、FAQ、对比表 |
| A+尾段 | 购买确认 | 包装清单、售后、适配说明、注意事项 |

## 必须避免

- 把 A9/COSMO/Rufus 写成确定的排名公式
- 为了算法优化而堆砌不自然关键词
- 用未确认参数做卖点
- 把评论痛点写成恐吓式文案
- 使用竞品原图、品牌、文案、参数或完整版式
- 用 A+参考图跨阶段指导主图/副图，或用主图/副图参考图指导 A+
