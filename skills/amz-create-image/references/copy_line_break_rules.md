# 图片文案换行规则

## 主标题

- 1-2行
- 每行2-5个英文词
- 使用断行版

示例：

```text
No Hardwiring
Needed
```

## 副标题

- 1-2行
- 用于补充利益点

示例：

```text
Screw-Mounted Base
Clean Wireless Look
```

## 子项

每个功能独立成行：

```text
Type-C Charging
Touch & Remote Control
30-Min Timer
```

## 禁止

```text
Type-C charging touch remote control wireless installation timer memory function
```
