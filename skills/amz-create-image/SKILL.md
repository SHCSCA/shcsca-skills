# amz-create-image

## 定位

把 Amazon 运营判断转成摄影师和美工一眼能执行的 Excel 需求稿。本 Skill 不直接生成最终商品图。

默认交付必须简洁：

- 主图/副图阶段只交付 `主图副图` 1张工作表。
- A+阶段在已确认的工作簿中增加 `A+需求`，最终总计2张工作表。
- 不把竞品地图、关键词、Review、运营分析、验收、合规等后台思考拆成十几张 Sheet。
- 只有用户明确要求详细运营分析表时，才增加独立分析页。

基础模板：

`templates/amz-create-image_workbook.xlsx`

标准版式：

`templates/amz-create-image_workbook_layout_v2.md`

生成或修订前必须阅读：

- `references/output_spec.md`
- `references/phased_workflow.md`
- `references/reference_image_rules.md`
- `references/excel_style_spec.md`
- 高级 A+ 时再读 `references/premium_aplus_compact_template.md`

## 核心方法

在后台完成以下判断，但只把结论写进对应图片行：

- 产品定位、目标人群、价格带与变体差异
- 核心品类词、功能词、场景词、痛点词与问题型词
- A9 点击与转化阻碍
- COSMO 的人群、任务、场景、痛点与搭配意图
- Rufus 可能回答的购物问题
- Review/VOC 好评动机、差评痛点、退货原因与 Q&A
- 竞品信息层级、视觉钩子和未满足疑虑
- 真实供货、配件、说明书、认证、材质、续航与安全边界

不要声称掌握 Amazon 未公开排名公式。详细运营映射见：

`references/amazon_operation_capabilities.md`

## 分阶段门禁

### Phase 0：资料确认

收集并核实：

- 产品名称、型号、站点、类目、品牌
- 售价/价格带、父子体、变体、套装数量
- 核心卖点、尺寸、重量、材质、配件、包装
- 安装/使用方式、说明书限制、禁用表达
- 关键词、广告词、自然词、Review/VOC、竞品 ASIN

资料不足时只输出缺口清单，不猜参数。

美国站涉及尺寸和重量时：

- `cm × 0.3937 = in`
- `kg × 2.20462 = lb`

美工执行列优先写 `in/lb`，并保留原始 `cm/kg` 核对。

### Phase 1：主图/副图

读取或搜索同阶段参考图：

- 搜索结果页与竞品主图
- 竞品副图、功能图、场景图
- 尺寸、安装、包装图

只生成 `主图副图` Sheet。默认 1张主图＋7张副图，共8行；产品特别简单可减到7张，安装复杂或变体多可扩到9张，但不增加后台分析 Sheet。

固定六列：

| 列 | 内容 |
|---|---|
| A | 图号 |
| B | 适用链接 |
| C | 画面／拍摄要求 |
| D | 英文文案（断行版） |
| E | 参考图 |
| F | 备注／禁用 |

每张图必须说明：

- 给哪个链接或变体使用
- 拍什么、怎么摆、主体与留白如何处理
- 图片内/原生字段写什么
- 参考哪张图、只参考什么
- 哪些参数、动作和表达禁止出现

图1和包装/数量图必须与真实售卖数量一致。共用图和分别出图要写清楚。

### Phase 2：验收

交付主图/副图稿后停止。用户明确回复“确认”“通过”“继续A+”等，才进入下一阶段。

若用户提出修改，先修订原工作簿，不提前生成 A+。

### Phase 3：A+参考图

优先读取用户已提供的独立 A+ 横幅、功能模块、场景模块、对比表或竞品 A+ 截图。

没有合格 A+参考图时，全网补充同类型 A+ 参考；不得拿主图、竞品主图或普通副图截图硬套 A+。

### Phase 4：A+需求

以已确认的主图/副图工作簿为源文件，新增或填充 `A+需求` Sheet，另存新版本。最终文件保留两张执行页：

- `主图副图`
- `A+需求`

固定六列：

| 列 | 内容 |
|---|---|
| A | 模块/帧 |
| B | 适用链接、模块类型或标签 |
| C | 画面／构图要求或原生文案 |
| D | 英文文案（断行版）或双端构图 |
| E | A+参考图 |
| F | 备注、Alt Text 与禁用 |

普通 A+ 按静态模块规划；确认用户拥有高级 A+ 后，优先评估互动模块。

## 高级 A+ 默认结构

默认规划5个模块，最多7个；按产品内容调整：

1. `Premium Full Image`：品牌首屏
2. `Premium Navigation Carousel`：功能轮播
3. 使用教育：Full Image、Hotspots 或 Regimen Carousel 三选一
4. `Premium Simple Image Carousel`：场景轮播
5. `Premium Comparison Table 2`：同品牌变体/产品选择

若不足2个可关联产品，模块5改用 Q&A、视频或技术规格；不得强行做对比表。

### 高级 A+ 表格排版

A+ Sheet 必须先列出 M1–M5 主模块总览。凡出现轮播，必须在主模块区下方另外拆出详细分区：

- 黄色分隔条：`M2 功能轮播详细拆分`
- 蓝色六列表头
- 每帧一行，分别写桌面图、手机图、原生字段、参考图、Alt Text 与禁用
- 黄色分隔条：`M4 场景轮播详细拆分`
- 蓝色六列表头
- 每帧一行

不得把多个轮播帧挤在一个单元格内，也不得只写“4 Panels”而没有帧级执行要求。

双轮播规则：

- 功能轮播回答“有什么、如何工作”，使用2–5帧。
- 场景轮播回答“谁、在哪里、什么时候用”，使用2–6帧；模板默认预留5帧。
- 每帧只表达一个功能或一个场景。
- 场景轮播不能只是同一功能图换背景。
- 内容不足时不强制双轮播。
- 需要双端图的模块，桌面与手机必须分别构图，不得只做自动裁切。
- 常用双端尺寸：桌面 `1464 × 600`，手机 `600 × 450`。
- 标题、正文、导航标签优先放 Amazon 原生字段，图片内不重复堆长文案。

具体帧数、字符限制、对比表边界和官方来源见：

`references/premium_aplus_compact_template.md`

## 参考图规则

### 参考图覆盖率

- 每个需要视觉执行的主图、副图、A+模块和轮播帧都必须有真实参考图。
- 原生 Q&A、技术规格等纯文本模块不需要图片，但 E 列必须明确写 `原生文本模块｜无需上传图片`，不得留空。
- 找不到当前竞品对应图型时继续全网搜索，不允许以“竞品没有”为由留空。

### 找图顺序

1. 用户提供的同阶段参考图
2. Amazon 直接竞品
3. Amazon 其他同类商品
4. Walmart / Home Depot / Lowe’s / Target
5. 品牌官网或其他可信电商平台

参考图必须与当前图型匹配：主图对主图、场景对场景、尺寸对尺寸、安装对安装、A+对 A+。

### 图片交付模式

默认使用远程图片公式：

```excel
=IMAGE("https://...","APLUS_REF_01",0)
```

原因：在目标 Excel/WPS 环境允许外部内容后，可直接显示，且不会出现部分兼容环境无法渲染嵌入绘图对象的问题。

要求：

- 只使用可直接访问的 HTTPS 图片地址。
- 同一行同时写参考编号、参考点、来源网址和禁止照抄点。
- 远程图片打不开时应更换来源，不得静默留空。
- 不使用 WPS `DISPIMG`。
- 不承诺断网可见。

只有用户明确要求“离线可见/实体嵌图”时才改用二进制嵌图；交付前必须在目标 Excel/WPS 环境完成可视验证。未经目标软件验证，不得声称“打开即见”。

主图/副图与 A+参考图必须严格分阶段。只学习信息层级和构图，不复制竞品 Logo、人物、文案、参数或完整配色。

详细规则见：

`references/reference_image_rules.md`

## 文案与合规

文案必须提供实际可排版的断行版：

```text
主标题：
No Hardwiring
Needed

副标题：
Clean Wireless Look
```

详细断行规则见：

`references/copy_line_break_rules.md`

所有事实必须由实物、说明书、包装或可靠数据支持。禁止：

- 医疗、治疗、止痛、恢复、循环改善等无证据宣称
- Before/After、百分比结果、极限词
- 价格、折扣、Best Seller、媒体背书
- 未确认的续航、接口、防水、材质、认证、尺寸或兼容性
- 竞品品牌、Logo、原图、文案或参数
- 危险动作、错误部位、错误安装或错误套装数量

## Excel 与交付质量

必须使用简版模板并保持：

- 顶部深蓝标题栏、产品元信息区、蓝色表头、浅蓝交替卡片、红色风险提示、黄色轮播/交付提示
- 修订现有工作簿时保留原顶部样式、列宽、行高、冻结窗格和轮播分区结构
- 关闭网格线、冻结执行表头、固定列宽和参考图行高
- 主图/副图每图一行；A+主模块每模块一行；轮播在下方单独拆帧
- 无本地路径列、无空白分析 Sheet、无 WPS 专用图片公式
- Excel 可正常打开，中文和英文不截断
- 公式错误扫描为0
- 每个应有参考图的行均已填入远程 `IMAGE()` 公式或已验证的实体图片
- 所有 Sheet 至少完成一次结构和可视检查

样式见：

`references/excel_style_spec.md`

交付前执行：

`references/checklist.md`
