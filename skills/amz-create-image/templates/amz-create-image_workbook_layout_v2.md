# amz-create-image 标准输出模板 v2

本文件定义 `amz-create-image_workbook.xlsx` 的标准视觉与结构。生成新文件或修订旧文件时均以此为基准。

## 一、主图副图 Sheet

### 1. 顶部区

- A1:F1 合并：深蓝标题栏，白色加粗标题。
- A2:A7：浅蓝标签列。
- B:C：左侧内容区。
- D：右侧标签列。
- E:F：右侧内容区。

建议字段：

| 行 | 左侧 | 右侧 |
|---|---|---|
| 2 | 产品名称 | 站点 |
| 3 | 品牌 | 款式/变体 |
| 4 | 图片规格 | - |
| 5 | 出图规则 | - |
| 6 | 核心卖点 | - |
| 7 | 统一禁用 | - |

### 2. 执行区

第9行为蓝色六列表头：

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 图号 | 适用链接 | 画面／拍摄要求 | 英文文案（断行版） | 参考图 | 备注／禁用 |

第10行起每图一行。默认8行：图1主图＋图2–8副图。

参考图列默认写：

```excel
=IMAGE("https://...","REF_01",0)
```

## 二、A+需求 Sheet

### 1. 顶部区

- A1:F1 合并：深蓝标题栏。
- A2:A7：浅蓝标签列。
- B:C：左侧内容区。
- D：右侧标签列。
- E:F：右侧内容区。

建议字段：

| 行 | 左侧 | 右侧 |
|---|---|---|
| 2 | 产品名称 | 站点 |
| 3 | 品牌 | 方案 |
| 4 | 模块结构 | - |
| 5 | 图片规格 | - |
| 6 | 核心表达 | - |
| 7 | 统一禁用 | - |

### 2. 主模块总览区

第9行为蓝色六列表头：

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 模块/帧 | 适用链接/模块类型 | 画面/构图要求 | 英文文案（断行版） | A+参考图 | 备注/Alt Text/禁用 |

第10行起先列 M1–M5 主模块总览。

- M1：品牌首屏
- M2：功能轮播概要
- M3：使用教育
- M4：场景轮播概要
- M5：对比表/Q&A/视频/技术规格

若 M5 为原生 Q&A 或技术规格，E列填写：

`原生文本模块｜无需上传图片`

### 3. 功能轮播详细区

主模块总览之后增加：

- 黄色合并分隔条：`模块说明｜M2 功能轮播详细拆分（N帧，每帧单独出桌面图 + 手机图）`
- 下一行重复蓝色六列表头。
- 每个 Panel 单独一行。

每帧必须包含：

- Panel 编号与功能名
- Desktop 1464×600
- Mobile 600×450
- 画面构图要求
- Navigation/Subheadline/Headline/Body 字段及字符上限
- 真实 A+参考图
- Alt Text 与禁用

### 4. 场景轮播详细区

功能轮播详细区之后增加：

- 黄色合并分隔条：`模块说明｜M4 场景轮播详细拆分（N帧，每帧单独出桌面图 + 手机图）`
- 下一行重复蓝色六列表头。
- 每个场景 Panel 单独一行。

每帧必须包含：

- Panel 编号与场景名
- Desktop 1464×600
- Mobile 600×450
- 桌面/手机分别构图要求
- Headline/Body 字段及字符上限
- 真实 A+参考图
- Alt Text 与禁用

## 三、样式参数

### 颜色

- 深蓝标题：`#1F4E78`
- 蓝色表头：`#2F75B5`
- 浅蓝标签：`#DDEBF7`
- 交替卡片：`#FFFFFF` / `#F4F9FC`
- 黄色分隔：`#FFF2CC`
- 风险红：`#FCE4E4` / `#C00000`
- 边框：`#A9C2D3`

### 列宽建议

| 列 | 主图副图 | A+需求 |
|---|---:|---:|
| A | 14–16 | 14–16 |
| B | 22–26 | 24–28 |
| C | 48–54 | 48–54 |
| D | 36–42 | 38–42 |
| E | 28–36 | 28–36 |
| F | 40–46 | 40–46 |

### 行高建议

- 标题：26–30
- 元信息：32–60
- 表头：22–26
- 图片执行行：110–140
- 黄色分隔条：20–24

## 四、参考图模式

默认：远程 `IMAGE()` 公式。

- 用户在 Excel/WPS 中允许外部内容后显示。
- 地址必须是直接 HTTPS 图片文件地址。
- 地址失效时更换来源。
- 不使用 `DISPIMG`。
- 不承诺断网可见。

实体嵌图仅在用户明确要求离线可见时使用，并必须在目标软件完成可视验证。

## 五、修订规则

修改已有文件时：

- 不重建顶部区域。
- 不丢失标题栏、元信息区、表头、分隔条和交替卡片样式。
- 不改变既有列顺序。
- 轮播新增内容必须进入独立详细区。
- 改图片时只替换 E列公式/图片，不破坏其他单元格格式。

## 六、验收

- 主图副图阶段只有1张 Sheet。
- A+阶段只有2张 Sheet。
- 每个视觉执行行都有参考图。
- Q&A等纯文本模块有明确无需图片说明。
- M2/M4轮播按帧拆分。
- 顶部样式没有丢失。
- 无公式错误、空白图片占位框、路径列或 WPS 专用公式。
