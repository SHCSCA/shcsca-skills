# amz-create-image v8

Amazon 主图、副图、普通 A+ 与高级 A+ 简版图片需求稿 Skill。

## v8 关键变化

- 将旧版16张分析 Sheet 改为美工可直接执行的2张简表。
- 主图/副图阶段只交付 `主图副图`。
- A+阶段在原文件增加 `A+需求`，最终仍只有2张工作表。
- 每张图片或模块固定使用六列：编号、适用范围、画面要求、英文文案、参考图、备注/禁用。
- 高级 A+ 默认评估5模块结构，并支持功能轮播＋场景轮播。
- 功能轮播按 `Premium Navigation Carousel` 规划2–5帧。
- 场景轮播按 `Premium Simple Image Carousel` 规划2–6帧，模板默认预留5帧。
- 桌面 `1464 × 600` 与手机 `600 × 450` 需要分别构图。
- 参考图必须嵌入对应行，不使用路径或 WPS `DISPIMG`。
- 运营分析仍在后台完成，不再堆给摄影师/美工。
