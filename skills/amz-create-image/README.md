# amz-create-image v9

Amazon 主图、副图、普通 A+ 与高级 A+ 简版图片需求稿 Skill。

## v9 关键变化

- 保留“主图副图阶段 1 张表、A+ 完成后 2 张表”的简版交付。
- 参考图支持两种交付模式：
  - 默认 `IMAGE()` 远程图片公式，适合用户允许外部内容后的 Excel/WPS 环境。
  - 用户明确要求离线时才使用实体嵌图，并且必须在目标软件中完成可视验收。
- 每个需要视觉参考的执行行都必须有参考图；原生 Q&A、技术规格等纯文本模块必须明确写“无需图片”，不得留空。
- 同类竞品找不到对应图型时，按 Amazon 同类商品 → Walmart/Home Depot/Lowe’s/Target → 品牌官网/其他可信电商平台补图，不允许空白交付。
- 高级 A+ 采用“主模块总览 + 轮播详细拆分”结构：
  - M1–M5 先做主模块总览。
  - 功能轮播和场景轮播分别在下方单独分区，每帧一行、每帧单独参考图。
- A+ 阶段必须保留顶部标题、元信息区、蓝色表头、黄色轮播分隔条和原主图副图样式。
- 桌面 `1464 × 600` 与手机 `600 × 450` 必须分别构图，不做机械裁切。
- 运营分析仍在后台完成，不把关键词、Review、竞品地图等拆成额外交付 Sheet。
